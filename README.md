## About

I like understanding how things work at the level most people don't bother with — how a JVM actually schedules threads, why a tree stays balanced, or what's actually happening mathematically when an image gets transformed or a system gets modeled. That curiosity is what pulls me between backend architecture and the math underneath it — linear algebra, matrices, vector spaces — not just using them, but building real intuition for why they work.

Most recently, I've been building **AksharaNexus**, a multi-portal platform for structured historical documentation — think version control semantics applied to civilizational data, with a Spring Boot backend, an AI-assisted research layer, and JavaFX/Flutter clients across desktop and mobile. On the side, I spend a lot of time working through linear algebra and its applications properly, from image processing to systems that lean on matrix and vector operations under the hood.

**Currently exploring:** persistent data structures, TLS/security internals, and the linear algebra behind image processing.
